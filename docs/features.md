# VitoCare Features

## User Roles

### 1. Patient

- Create Account
- Login
- View Profile
- View Prescriptions
- Receive Offline Medicine Reminders
- View Appointments
- Mark Medicine as Taken
- View Health History
- Request Volunteer Help

---

### Patient Registration

- Full Name
- Age
- Gender
- Mobile Number
- Address
- Blood Group
- Emergency Contact
- Health Issue
- Assigned Hospital
- Assigned Doctor

---

### 2. Doctor

- Login
- View Patients
- Add Diagnosis
- Upload Prescription
- Add Medicines
- Schedule Appointment
- View Patient History

---

### 3. Hospital Assistant

- Login
- Register Patients
- Create Patient Accounts
- Upload Prescriptions
- Schedule Appointments
- Update Patient Details

---

### 4. Volunteer

- Login
- View Assigned Patients
- Receive Visit Notifications
- Update Patient Condition
- Confirm Home Visits
- Report Emergencies

---

### 5. Administrator

- Login
- Create Doctor IDs
- Create Volunteer IDs
- Create Hospital Assistant IDs
- Manage Hospitals
- Manage Users
- View Reports
- View Analytics

---

# Hospital Module

The application will contain a list of registered hospitals.

Each hospital will include:

- Hospital Name
- Address
- Contact Number
- Available Doctors
- Departments
- Working Hours
