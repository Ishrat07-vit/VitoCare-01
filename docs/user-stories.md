# VitoCare User Stories

## Introduction

User stories describe the requirements of VitoCare from the perspective of its users.

They follow the format:

> As a [user], I want to [action], so that [benefit].

---

# 1. Patient User Stories

## Account Management

### US-P01
As a patient, I want to create an account so that I can access VitoCare services.

### US-P02
As a patient, I want to log in securely so that I can access my healthcare information.

### US-P03
As a patient, I want to view and update my profile so that my information remains accurate.

## Medicines

### US-P04
As a patient, I want to view my prescribed medicines so that I know what medicines I need to take.

### US-P05
As a patient, I want to receive medicine reminders so that I do not forget to take my medicines.

### US-P06
As a patient, I want to mark a medicine as taken so that my medicine history can be tracked.

## Appointments

### US-P07
As a patient, I want to view my appointments so that I know when I need to visit the doctor.

### US-P08
As a patient, I want to receive appointment information so that I do not miss my appointments.

## Healthcare Support

### US-P09
As a patient, I want to view my health history so that I can keep track of my previous healthcare information.

### US-P10
As a patient, I want to request volunteer assistance so that I can receive community healthcare support.

---

# 2. Doctor User Stories

### US-D01
As a doctor, I want to log in securely so that I can access my professional dashboard.

### US-D02
As a doctor, I want to view my assigned patients so that I can provide appropriate healthcare.

### US-D03
As a doctor, I want to view a patient's medical history so that I can make informed decisions.

### US-D04
As a doctor, I want to add a diagnosis so that the patient's medical record is updated.

### US-D05
As a doctor, I want to create prescriptions so that patients know which medicines to take.

### US-D06
As a doctor, I want to schedule appointments so that patients can meet me at the appropriate time.

---

# 3. Hospital Assistant User Stories

### US-H01
As a hospital assistant, I want to log in so that I can access hospital management features.

### US-H02
As a hospital assistant, I want to register patients so that patients can access VitoCare.

### US-H03
As a hospital assistant, I want to create patient accounts so that patients can use the platform.

### US-H04
As a hospital assistant, I want to update patient information so that patient records remain accurate.

### US-H05
As a hospital assistant, I want to schedule appointments so that patients can meet doctors.

### US-H06
As a hospital assistant, I want to upload prescriptions so that patients can access their prescription information.

---

# 4. Volunteer User Stories

### US-V01
As a volunteer, I want to log in so that I can access my assigned tasks.

### US-V02
As a volunteer, I want to view assigned patients so that I know whom I need to assist.

### US-V03
As a volunteer, I want to receive visit requests so that I can provide home-based assistance.

### US-V04
As a volunteer, I want to confirm home visits so that the system knows that the visit was completed.

### US-V05
As a volunteer, I want to update a patient's condition after a visit so that healthcare workers have updated information.

### US-V06
As a volunteer, I want to report emergencies so that appropriate healthcare support can be provided.

---

# 5. Administrator User Stories

### US-A01
As an administrator, I want to log in securely so that I can manage the platform.

### US-A02
As an administrator, I want to manage users so that the platform remains organized.

### US-A03
As an administrator, I want to create doctor IDs so that authorized doctors can access the system.

### US-A04
As an administrator, I want to create volunteer IDs so that authorized volunteers can access the system.

### US-A05
As an administrator, I want to create hospital assistant IDs so that authorized staff can access the system.

### US-A06
As an administrator, I want to manage hospitals so that hospital information remains up to date.

### US-A07
As an administrator, I want to view reports and analytics so that I can monitor the platform.

---

# 6. System User Stories

### US-S01
As a system, I want to authenticate users based on their roles so that users can access only the features relevant to them.

### US-S02
As a system, I want to send medicine reminders according to prescribed schedules so that patients can follow their medication plans.

### US-S03
As a system, I want to maintain healthcare records so that authorized users can access relevant patient information.

### US-S04
As a system, I want to support offline access to essential information so that patients can continue using important features when internet connectivity is unavailable.
